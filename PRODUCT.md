# RISA admin

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
RISA administrators and editors updating the association website.

## Product Purpose
Manage News, Activities and Personnel using the established content workflows.

## Operating Context
Authenticated Thai admin workspace with Thai and English content fields. News and Activities use content, image, preview and publication steps. Personnel uses the existing profile editor and visibility confirmation.

## Capabilities and Constraints
Preserve existing role checks, authentication, routes and content actions. Settings and inline editing stay disabled. Add no admin capabilities or production QA content. The public website and completed footer release are outside this redesign.

## Brand Commitments
RISA name and logo remain. The user selected 01 Constellation Map, with dark cosmic styling and Thai/English versions. The original hand-drawn task map and downloaded ConstellationTH.png / ConstellationEN.png are the reference authority. The earlier Modular Mosaic draft is preserved on its own branch.

## Evidence on Hand
Existing admin components and routes; the selected concept images and IMG_0441.JPG supplied in Downloads. Preview data must be synthetic.

## Accessibility & Inclusion
Readable Thai and English, keyboard operation, VoiceOver semantics, responsive layouts and sufficient contrast.
